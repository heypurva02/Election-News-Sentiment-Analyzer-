# Election News Sentiment Analyzer

This project is a C++ based Election News Sentiment Analyzer designed to evaluate the sentiment of political news headlines. The system analyzes user-provided headlines, identifies sentiment using predefined keyword dictionaries, and classifies the news as Positive, Negative, or Neutral.

## Features
- Headline sentiment analysis
- Positive, Negative, and Neutral classification
- Keyword-based sentiment detection
- Sentiment score calculation
- Statistical summary generation
- Menu-driven console interface

## Technologies Used
- C++
- Standard Template Library (STL)
- File Handling
- String Processing

## Applications
- Media sentiment monitoring
- Election trend analysis
- News content evaluation
- Educational demonstration of sentiment analysis concepts
